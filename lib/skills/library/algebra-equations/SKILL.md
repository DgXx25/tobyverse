# Algebra and equations

Apply only the methods relevant to the current request. Follow the user's language and desired detail; a request for roots or a final answer does not require a worked lesson. When working is helpful, show enough transformations to make the answer easy to check.

For a linear equation, expand or collect terms as needed and preserve equality while isolating the unknown. For example, 2(x − 3) = 10 gives x − 3 = 5, so x = 8. Substitution gives 2(8 − 3) = 10.

For a quadratic ax² + bx + c = 0 with a ≠ 0, factoring is convenient when simple factors exist; otherwise use completing the square or the quadratic formula. For example, x² − 5x + 6 = (x − 2)(x − 3), so the equation x² − 5x + 6 = 0 has roots 2 and 3. An expression to factor is not itself an equation to solve.

Preserve domain restrictions from the original problem, especially nonzero denominators and real square roots. Dividing by an expression can discard its zero case; squaring can introduce extraneous candidates. Check candidates against the original equation when these operations occur. Specify real or complex solutions when that distinction matters. These checks also apply when algebra supports a physics, calculus, or statistics calculation.
