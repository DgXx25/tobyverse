# Language reasoning

Preserve the requested source and target languages, register, dialect, and proficiency level. Give idiomatic wording rather than a word-for-word rendering when naturalness is requested; explain a meaningful ambiguity briefly. For grammar, connect a pattern to its context and use natural examples only when useful. Do not translate into English merely because internal guidance is written in English.
