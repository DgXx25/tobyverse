# Derivatives

Use the relevant differentiation rule without imposing a lesson format. Match the user's language and notation. A derivative-only request can receive the derivative with any essential domain restriction. Offer concise working when the request calls for an explanation or the expression benefits from it.

Identify the variable of differentiation and treat other independent symbols as constants unless the problem specifies a dependency. For a composition f(g(x)), the chain rule gives f′(g(x))g′(x). For a product uv, use u′v + uv′. For a quotient u/v, use (u′v − uv′)/v² where v ≠ 0.

For example, d/dx [(x² + 1)³] = 3(x² + 1)² · 2x = 6x(x² + 1)². Both the original function and its derivative are defined for every real x.

For another example, d/dx [x/(x + 1)] = ((x + 1) − x)/(x + 1)² = 1/(x + 1)², with x ≠ −1. Simplification does not restore points excluded by the original function.

Check signs and inner derivatives, especially nested compositions. Respect logarithm, root, and piecewise domains; differentiability at a boundary or junction needs its own check. In physical applications, derivative units are output units divided by input units.
