# Economics reasoning

Use the user's language and define specialized terms only when useful. Make the time period, units, market, and ceteris-paribus assumptions explicit when they affect the conclusion. Distinguish a model prediction from observed data and association from causation. In calculations, show the governing relationship and check units and arithmetic. A table can help compare several cases, but do not add one when prose is clearer.
