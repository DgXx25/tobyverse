# Geography reasoning

Use the user's language and requested depth. Identify location, scale, time period, units, and data date when they affect an explanation. Link spatial patterns to plausible physical or human causes without treating correlation as proof. Distinguish climate from weather and a model projection from an observation. Use named regions and directions precisely; a map, chart, or concise comparison can help when it adds distinct information.
